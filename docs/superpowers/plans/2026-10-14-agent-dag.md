# agent-dag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code mod that draws a live tree (and card view) of the session's agents, their status, cost, current tool and inter-agent messages in a docked terminal pane, with a `/dag` command.

**Architecture:** Engine events (`agent.spawn`, `turn.start`, `tool.call`, `turn.complete`, `session.send`, a clock tick) are translated into plain `DagEvent` values and folded by a pure reducer in `hooks/model.ts` into a `DagState` kept in `$.state`. A pure layout module `hooks/draw.ts` turns that state into rows of styled text segments. `hooks/register.tsx` is the only file that touches `$`: it wires events to the reducer, opens the pane, registers `/dag`, and maps rows to `Box`/`Text`/`Button` elements.

**Tech Stack:** Claude Code function-hooks mod (TypeScript + JSX against the `claude-code` module), `claude plugin validate`, `claude plugin test`, `tsc`. No npm packages.

**Spec:** `docs/superpowers/specs/2026-10-14-agent-dag-design.md`

## Global Constraints

- Mod folder: `/home/qifei/.claude/dev-mods/b3ccd4af-0af7-430a-a74f-84384e69ff04/agent-dag/` (the git repo root; every path below is relative to it).
- Plugin name `agent-dag`, pane id `agent-dag`, pane title `Agents`, command `dag`, `$.state` plugin key `agent-dag`.
- The module runs with no DOM and no Node: no `setTimeout`, `Date.now`, `console`, `require`, `import()`. Time comes from `$.clock.now()` or the event; the test kit's `mock.clock` replaces `$.clock`.
- JSX compiles against the global `h`: never declare or import `h` or `Fragment`.
- Elements come from `$.ui.resolve(e)`; only `Box`, `Text`, `Button` are used. Colors are theme keys only: `text`, `subtle`, `claude`, `success`, `error`, `warning`.
- Every hook on a gating event (`agent.spawn`, `tool.call`, `session.send`) calls `next(e)` and carries `.catch(($, e, next) => next(e))` so a failure in the mod never changes the engine's behaviour.
- Glyph sets: unicode `◌ ◐ ○ ● ✓ ✗ ⊘ ├─ └─ │ → ▸` and ascii `. > o * + x - |- \`- | -> >`. The `ascii` set must contain no character above U+007F.
- Column drop order as the pane narrows: tool below 72, model below 60, tokens below 48, status word below 40; label never below 12 columns.
- Commit after every task with a conventional-commit message ending in `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Run `claude plugin validate .` and `claude plugin test .` from the mod folder before each commit from Task 3 on.

## Review Focus

1. **An event for an agent the mod never saw spawn** (a forked skill, an agent spawned before the mod loaded, a hot reload mid-session): the pane must still show it, labelled by its type under `main`, never throw. Pinned in Task 2 (`creates a node on the fly for an unknown agent id`).
2. **A turn.complete with no `usage`** (an interrupted turn, an API error): token sums must not become `NaN`. Pinned in Task 2 (`turn-end without usage keeps token counts`).
3. **A pane narrower than the shortest layout** (a 30-column dock): rows must not exceed the width and the label must still be readable. Pinned in Task 4 (`30 columns draws glyph + label only`).
4. **A message to an address that matches nothing** (a session id, a typo): the edge must still be listed with the raw address, not dropped and not crash the resolver. Pinned in Task 2 (`message to an unknown address keeps the raw address`).
5. **A person closes the pane, then another agent spawns**: the pane must stay closed; `/dag` reopens it. Pinned in Task 6 (`a person's close suppresses auto-open until /dag`).

`hooks/model.ts`:
```ts
import type { AgentNode, AgentStatus, DagState, MessageEdge, View } from '../types'

export const MAIN = 'main'
const RECENT_TOOLS = 6
const LAST_TEXT = 60
const ENDED: ReadonlySet<AgentStatus> = new Set(['completed', 'failed', 'killed'])

export type Usage = {
  input_tokens: number
  output_tokens: number
  cache_read_input_tokens: number
  cache_creation_input_tokens: number
}

export type ListedAgent = {
  id: string
  status: AgentStatus
  name?: string
  teammateId?: string
  description?: string
  type?: string
  parentId?: string
}

export type DagEvent =
  | { kind: 'spawn'; agentId: string; parentId: string; label: string; type: string;
      isTeammate: boolean; name?: string; teammateId?: string; workflowRunId?: string;
      model?: string; at: number }
  | { kind: 'turn-start'; agentId: string | undefined; at: number }
  | { kind: 'tool-start'; agentId: string | undefined; tool: string }
  | { kind: 'tool-end'; agentId: string | undefined; tool: string }
  | { kind: 'turn-end'; agentId: string | undefined; reason: 'answer' | 'aborted' | 'error' | 'refusal';
      usage?: Usage; at: number }
  | { kind: 'message'; from: string; to: string; text: string; at: number }
  | { kind: 'reconcile'; agents: ListedAgent[]; at: number }
  | { kind: 'tick'; at: number }
  | { kind: 'reset'; at: number }
  | { kind: 'set-flags'; view?: View; showMessages?: boolean; showTools?: boolean;
      isClosedByPerson?: boolean; hasOpened?: boolean }

export const loopId = (agentId: string | undefined): string => agentId ?? MAIN

const mainNode = (at: number): AgentNode => ({
  id: MAIN, label: 'main', type: 'session', isTeammate: false, status: 'idle',
  startedAt: at, turns: 0, inputTokens: 0, outputTokens: 0, toolCount: 0, recentTools: [],
})

export const freshState = (now: number, view: View): DagState => ({
  nodes: { [MAIN]: mainNode(now) },
  order: [MAIN],
  messages: [],
  view,
  showMessages: true,
  showTools: true,
  isClosedByPerson: false,
  hasOpened: false,
  tick: 0,
})

export const isActive = (s: DagState): boolean =>
  Object.values(s.nodes).some(n => n.status === 'running' || n.status === 'pending')

export const children = (s: DagState, id: string): AgentNode[] =>
  s.order.map(k => s.nodes[k]).filter(n => n && n.id !== MAIN && (n.parentId ?? MAIN) === id)

export const resolveAddress = (s: DagState, to: string): string => {
  if (s.nodes[to]) return to
  const hit = s.order.map(k => s.nodes[k]).find(n => n.name === to || n.teammateId === to)
  return hit ? hit.id : to
}

export const shortModel = (id: string | undefined): string => {
  if (!id) return ''
  for (const family of ['fable', 'opus', 'sonnet', 'haiku']) {
    if (id.includes(family)) return family
  }
  const last = id.split('/').pop() ?? id
  return last.slice(0, 8)
}

const placeholder = (id: string, at: number, parentId = MAIN, label = 'agent', type = 'agent'): AgentNode => ({
  id, parentId, label, type, isTeammate: false, status: 'pending', startedAt: at,
  turns: 0, inputTokens: 0, outputTokens: 0, toolCount: 0, recentTools: [],
})

/** Returns state with `id` present (created as a placeholder when absent). */
const ensure = (s: DagState, id: string, at: number, parentId = MAIN, label?: string, type?: string): DagState => {
  if (s.nodes[id]) return s
  const withParent = parentId === MAIN || s.nodes[parentId] ? s : ensure(s, parentId, at)
  return {
    ...withParent,
    nodes: { ...withParent.nodes, [id]: placeholder(id, at, parentId, label, type) },
    order: [...withParent.order, id],
  }
}

const patch = (s: DagState, id: string, fn: (n: AgentNode) => AgentNode): DagState => ({
  ...s, nodes: { ...s.nodes, [id]: fn(s.nodes[id]) },
})

const endStatus = (n: AgentNode, reason: 'answer' | 'aborted' | 'error' | 'refusal'): AgentStatus => {
  if (reason === 'aborted') return 'killed'
  if (reason === 'error' || reason === 'refusal') return 'failed'
  return n.id === MAIN || n.isTeammate ? 'idle' : 'completed'
}

export const apply = (s: DagState, ev: DagEvent): DagState => {
  switch (ev.kind) {
    case 'spawn': {
      const base = ensure(ensure(s, ev.parentId, ev.at), ev.agentId, ev.at, ev.parentId)
      return patch(base, ev.agentId, n => ({
        ...n, parentId: ev.parentId, label: ev.label, type: ev.type, isTeammate: ev.isTeammate,
        name: ev.name ?? n.name, teammateId: ev.teammateId ?? n.teammateId,
        workflowRunId: ev.workflowRunId ?? n.workflowRunId, model: ev.model ?? n.model,
        status: 'pending', startedAt: ev.at, endedAt: undefined, currentTool: undefined,
      }))
    }
    case 'turn-start': {
      const id = loopId(ev.agentId)
      return patch(ensure(s, id, ev.at), id, n => ({ ...n, status: 'running', turns: n.turns + 1, endedAt: undefined }))
    }
    case 'tool-start': {
      const id = loopId(ev.agentId)
      return patch(ensure(s, id, 0), id, n => ({ ...n, currentTool: ev.tool }))
    }
    case 'tool-end': {
      const id = loopId(ev.agentId)
      return patch(ensure(s, id, 0), id, n => ({
        ...n,
        toolCount: n.toolCount + 1,
        recentTools: [...n.recentTools, ev.tool].slice(-RECENT_TOOLS),
        currentTool: n.currentTool === ev.tool ? undefined : n.currentTool,
      }))
    }
    case 'turn-end': {
      const id = loopId(ev.agentId)
      return patch(ensure(s, id, ev.at), id, n => ({
        ...n,
        status: endStatus(n, ev.reason),
        endedAt: ev.at,
        currentTool: undefined,
        inputTokens: n.inputTokens + (ev.usage?.input_tokens ?? 0),
        outputTokens: n.outputTokens + (ev.usage?.output_tokens ?? 0),
      }))
    }
    case 'message': {
      const to = resolveAddress(s, ev.to)
      const text = ev.text.replace(/\s+/g, ' ').trim().slice(0, LAST_TEXT)
      const i = s.messages.findIndex(m => m.from === ev.from && m.to === to)
      const edge: MessageEdge = i < 0
        ? { from: ev.from, to, count: 1, lastAt: ev.at, lastText: text }
        : { ...s.messages[i], count: s.messages[i].count + 1, lastAt: ev.at, lastText: text }
      const messages = i < 0 ? [...s.messages, edge] : s.messages.map((m, k) => (k === i ? edge : m))
      return { ...s, messages }
    }
    case 'reconcile': {
      let out = s
      for (const a of ev.agents) {
        out = ensure(out, a.id, ev.at, a.parentId ?? MAIN, a.description || a.name || a.type, a.type)
        out = patch(out, a.id, n => {
          const takes = a.status !== 'running' && a.status !== 'pending' && !ENDED.has(n.status)
          return {
            ...n,
            name: n.name ?? a.name,
            teammateId: n.teammateId ?? a.teammateId,
            status: takes ? a.status : n.status,
            endedAt: takes && ENDED.has(a.status) ? ev.at : n.endedAt,
          }
        })
      }
      return out
    }
    case 'tick':
      return { ...s, tick: s.tick + 1 }
    case 'reset':
      return { ...freshState(ev.at, s.view), showMessages: s.showMessages, showTools: s.showTools,
        isClosedByPerson: s.isClosedByPerson, hasOpened: s.hasOpened }
    case 'set-flags': {
      const { kind: _k, ...flags } = ev
      const defined = Object.fromEntries(Object.entries(flags).filter(([, v]) => v !== undefined))
      return { ...s, ...defined }
    }
  }
}
```

```ts
import type { AgentStatus, GlyphSet } from '../types'

export type Glyphs = {
  status: Record<AgentStatus, string>
  tee: string
  elbow: string
  pipe: string
  blank: string
  arrow: string
  chip: string
  group: string
}

export const GLYPHS: Record<GlyphSet, Glyphs> = {
  unicode: {
    status: { pending: '◌', running: '◐', waiting: '○', idle: '●', completed: '✓', failed: '✗', killed: '⊘' },
    tee: '├─', elbow: '└─', pipe: '│ ', blank: '  ', arrow: '→', chip: '▸', group: '▸',
  },
  ascii: {
    status: { pending: '.', running: '>', waiting: 'o', idle: '*', completed: '+', failed: 'x', killed: '-' },
    tee: '|-', elbow: '`-', pipe: '| ', blank: '  ', arrow: '->', chip: '>', group: '>',
  },
}

export const STATUS_WORD: Record<AgentStatus, string> = {
  pending: 'pending', running: 'running', waiting: 'waiting', idle: 'idle',
  completed: 'done', failed: 'failed', killed: 'killed',
}

export const STATUS_COLOR: Record<AgentStatus, { color: string; dim?: boolean }> = {
  pending: { color: 'subtle' },
  running: { color: 'claude' },
  waiting: { color: 'warning' },
  idle: { color: 'subtle', dim: true },
  completed: { color: 'success' },
  failed: { color: 'error' },
  killed: { color: 'error', dim: true },
}

export const fmtElapsed = (ms: number): string => {
  const s = Math.max(0, Math.floor(ms / 1000))
  if (s < 60) return `${s}s`
  const m = Math.floor(s / 60)
  if (m < 60) return `${m}m${String(s % 60).padStart(2, '0')}s`
  const h = Math.floor(m / 60)
  return `${h}h${String(m % 60).padStart(2, '0')}m`
}

export const fmtTokens = (n: number): string => {
  if (n < 1000) return String(n)
  if (n < 1_000_000) return `${(n / 1000).toFixed(1)}k`
  return `${(n / 1_000_000).toFixed(1)}M`
}

export const fit = (text: string, width: number, ellipsis = '…'): string => {
  if (width <= 0) return ''
  const chars = [...text]
  if (chars.length <= width) return text + ' '.repeat(width - chars.length)
  if (width === 1) return ellipsis
  return chars.slice(0, width - 1).join('') + ellipsis
}

export const padLeft = (text: string, width: number): string =>
  text.length >= width ? text : ' '.repeat(width - text.length) + text
```

```ts
import type { AgentNode, AgentStatus, DagState, GlyphSet } from '../types'
import { MAIN, children, shortModel } from './model'
import { GLYPHS, STATUS_COLOR, STATUS_WORD, fit, fmtElapsed, fmtTokens, padLeft } from './format'

export type Segment = { text: string; color?: string; dim?: boolean; bold?: boolean }
export type Row = Segment[]
export type LayoutOptions = { columns: number; glyphs: GlyphSet; now: number }
export type Card = { depth: number; status: AgentStatus; rows: Row[] }

const MIN_LABEL = 12
const MAX_MESSAGES = 12
const NAME_WIDTH = 18
const BARE_TYPES = new Set(['general-purpose', 'teammate', 'claude', 'session', 'agent'])

export const visibleColumns = (width: number) => ({
  status: width >= 40,
  tokens: width >= 48,
  model: width >= 60,
  tool: width >= 72,
})

const elapsedOf = (n: AgentNode, now: number): number =>
  (n.status === 'running' || n.status === 'pending' || n.endedAt === undefined ? now : n.endedAt) - n.startedAt

const labelOf = (n: AgentNode): string =>
  BARE_TYPES.has(n.type) || n.label === n.type ? n.label : `${n.type}: ${n.label}`

const ellipsisOf = (glyphs: GlyphSet) => (glyphs === 'ascii' ? '~' : '…')

/** A drawable item: a node, or a synthetic workflow group. */
type Item = {
  id: string
  label: string
  status: AgentStatus
  node?: AgentNode
  depth: number
  isLast: boolean
  trail: boolean[]   // for each ancestor depth, whether a pipe continues
  kids: Item[]
  members?: AgentNode[]   // set on a workflow group item
}

const groupStatus = (nodes: AgentNode[]): AgentStatus => {
  if (nodes.some(n => n.status === 'running')) return 'running'
  if (nodes.some(n => n.status === 'failed')) return 'failed'
  if (nodes.some(n => n.status === 'pending' || n.status === 'waiting')) return 'pending'
  if (nodes.every(n => n.status === 'completed' || n.status === 'killed')) return 'completed'
  return 'idle'
}

/** Children of `id` as items, with workflow agents folded into group items. */
const itemsUnder = (s: DagState, id: string, depth: number, trail: boolean[]): Item[] => {
  const kids = children(s, id)
  const out: Item[] = []
  const seenRuns = new Set<string>()
  for (const k of kids) {
    if (k.workflowRunId) {
      if (seenRuns.has(k.workflowRunId)) continue
      seenRuns.add(k.workflowRunId)
      const members = kids.filter(m => m.workflowRunId === k.workflowRunId)
      out.push({ id: `wf:${k.workflowRunId}`, label: `workflow ${k.workflowRunId}`, status: groupStatus(members),
        depth, isLast: false, trail, kids: [], members })
    } else {
      out.push({ id: k.id, label: labelOf(k), status: k.status, node: k, depth, isLast: false, trail, kids: [] })
    }
  }
  out.forEach((it, i) => {
    it.isLast = i === out.length - 1
    const nextTrail = [...trail, !it.isLast]
    const members = it.members
    it.kids = members
      ? members.map((m, j) => ({ id: m.id, label: labelOf(m), status: m.status, node: m, depth: depth + 1,
          isLast: j === members.length - 1, trail: nextTrail,
          kids: itemsUnder(s, m.id, depth + 2, [...nextTrail, j !== members.length - 1]) }))
      : itemsUnder(s, it.id, depth + 1, nextTrail)
  })
  return out
}

const flatten = (items: Item[]): Item[] => items.flatMap(it => [it, ...flatten(it.kids)])

const connector = (it: Item, g: typeof GLYPHS.unicode): string => {
  if (it.depth === 0) return ''
  const lead = it.trail.slice(1).map(more => (more ? g.pipe : g.blank)).join('')
  return lead + (it.isLast ? g.elbow : g.tee)
}

const statusSeg = (st: AgentStatus, text: string): Segment => ({ text, ...STATUS_COLOR[st] })

export const treeRows = (s: DagState, o: LayoutOptions): Row[] => {
  const g = GLYPHS[o.glyphs]
  const main = s.nodes[MAIN]
  const root: Item = { id: MAIN, label: 'main', status: main.status, node: main, depth: 0, isLast: true, trail: [], kids: [] }
  root.kids = itemsUnder(s, MAIN, 1, [true])
  const items = flatten([root])
  const cols = visibleColumns(o.columns)
  const ell = ellipsisOf(o.glyphs)

  // Fixed widths of the right-hand columns (including their leading space).
  const wStatus = cols.status ? 8 : 0   // ' running'
  const wElapsed = 7                    // ' 1h03m ' style, right aligned in 6 + space
  const wTokens = cols.tokens ? 7 : 0   // ' 12.4k'
  const wModel = cols.model ? 8 : 0     // ' sonnet '
  const wTool = cols.tool ? 10 : 0      // ' ToolSearc'
  const right = wStatus + wElapsed + wTokens + wModel + wTool

  return items.map(it => {
    const conn = connector(it, g)
    const glyph = g.status[it.status]
    const head = [...conn].length + [...glyph].length + 1
    const labelWidth = Math.max(MIN_LABEL, o.columns - head - right)
    const room = o.columns - head - labelWidth  // what is left for the right columns
    const n = it.node
    const row: Row = [
      { text: conn, dim: true },
      statusSeg(it.status, glyph),
      { text: ' ' + fit(it.label, labelWidth, ell), bold: it.depth === 0 },
    ]
    let used = 0
    const push = (w: number, text: string, extra: Partial<Segment> = {}) => {
      if (w === 0 || used + w > room) return
      used += w
      row.push({ text: padLeft(text, w), ...extra })
    }
    if (cols.status) push(wStatus, STATUS_WORD[it.status], STATUS_COLOR[it.status])
    push(wElapsed, n ? fmtElapsed(elapsedOf(n, o.now)) : '', { dim: true })
    if (cols.tokens) push(wTokens, n ? fmtTokens(n.inputTokens + n.outputTokens) : '', { dim: true })
    if (cols.model) push(wModel, n ? shortModel(n.model) : '', { dim: true })
    if (cols.tool) push(wTool, n?.currentTool ? fit(n.currentTool, wTool - 1, ell).trimEnd() : '', { color: 'claude' })
    return row
  })
}

export const cards = (s: DagState, o: LayoutOptions): Card[] => {
  const g = GLYPHS[o.glyphs]
  const dot = o.glyphs === 'ascii' ? ' - ' : ' · '
  const ell = ellipsisOf(o.glyphs)
  const main = s.nodes[MAIN]
  const root: Item = { id: MAIN, label: 'main', status: main.status, node: main, depth: 0, isLast: true, trail: [], kids: [] }
  root.kids = itemsUnder(s, MAIN, 1, [true])
  return flatten([root]).map(it => {
    const inner = o.columns - 4 - 2 * it.depth
    const n = it.node
    const rows: Row[] = [[statusSeg(it.status, g.status[it.status]), { text: ' ' + fit(it.label, inner - 2, ell).trimEnd(), bold: true }]]
    if (n) {
      const meta = [
        `${STATUS_WORD[n.status]} ${fmtElapsed(elapsedOf(n, o.now))}`,
        shortModel(n.model) || '?',
        fmtTokens(n.inputTokens + n.outputTokens),
        `${n.turns} turn${n.turns === 1 ? '' : 's'}`,
      ].join(dot)
      rows.push([{ text: fit(meta, inner, ell).trimEnd(), dim: true }])
      if (s.showTools) {
        const chips: Row = []
        if (n.recentTools.length) chips.push({ text: n.recentTools.join(' '), dim: true })
        if (n.currentTool) chips.push({ text: `${chips.length ? ' ' : ''}${g.chip} ${n.currentTool}`, color: 'claude' })
        if (!chips.length) chips.push({ text: 'no tools yet', dim: true })
        const total = chips.map(c => c.text).join('')
        if ([...total].length > inner) {
          rows.push([{ text: fit(total, inner, ell), dim: true }])
        } else rows.push(chips)
      }
    }
    return { depth: it.depth, status: it.status, rows }
  })
}

export const messageRows = (s: DagState, o: LayoutOptions): Row[] => {
  if (!s.showMessages || s.messages.length === 0) return []
  const g = GLYPHS[o.glyphs]
  const ell = ellipsisOf(o.glyphs)
  // Bare labels (no type prefix) so a sender and a receiver read as names.
  const nameOf = (id: string) => fit(s.nodes[id]?.label ?? id, NAME_WIDTH, ell).trimEnd()
  const hasQuote = o.columns >= 60
  // Two names, an arrow and spaces at most; narrower when the pane is.
  const pairWidth = Math.max(10, Math.min(2 * NAME_WIDTH + 5, o.columns - 4 - (hasQuote ? 20 : 0)))
  const rows: Row[] = [[{ text: 'messages', dim: true, bold: true }]]
  const sorted = [...s.messages].sort((a, b) => b.lastAt - a.lastAt).slice(0, MAX_MESSAGES)
  for (const m of sorted) {
    const pair = `  ${nameOf(m.from)} ${g.arrow} ${nameOf(m.to)}`
    const row: Row = [{ text: fit(pair, pairWidth, ell) }, { text: padLeft(String(m.count), 4), dim: true }]
    if (hasQuote) {
      const room = o.columns - pairWidth - 4 - 3   // space, two quotes
      if (room > 3) row.push({ text: ` "${fit(m.lastText, room, ell).trimEnd()}"`, dim: true })
    }
    rows.push(row)
  }
  return rows
}

export const summary = (s: DagState, glyphs: GlyphSet): string => {
  const agents = s.order.filter(id => id !== MAIN)
  const running = agents.filter(id => s.nodes[id].status === 'running').length
  const sep = glyphs === 'ascii' ? ' - ' : ' · '
  return `${agents.length} agent${agents.length === 1 ? '' : 's'}${sep}${running} running`
}

export const plainText = (rows: Row[]): string =>
  rows.map(r => r.map(seg => seg.text).join('').trimEnd()).join('\n')
```

```tsx
import { atom, read, update } from 'claude-code'
import type { Register } from 'claude-code'

import type { DagState, GlyphSet, View } from '../types'
import { MAIN, apply, freshState, isActive, loopId } from './model'
import type { DagEvent, ListedAgent } from './model'
import { cards, messageRows, plainText, summary, treeRows } from './draw'
import type { Row, Segment } from './draw'
import { STATUS_COLOR } from './format'

export const PANE = 'agent-dag'
const TITLE = 'Agents'
const TICK_MS = 1000
const RECONCILE_EVERY = 5
const CARDS_MIN_COLUMNS = 44

export const dag = atom({ plugin: 'agent-dag', key: 'dag' } as const, freshState(0, 'tree'), { shape: 'v1' })

type Options = { glyphs: GlyphSet; autoOpen: boolean; defaultView: View }

const readOptions = (raw: Readonly<Record<string, unknown>>): Options => ({
  glyphs: raw.glyphs === 'ascii' ? 'ascii' : 'unicode',
  autoOpen: raw.autoOpen !== false,
  defaultView: raw.defaultView === 'cards' ? 'cards' : 'tree',
})

export const register: Register = (on, rawOptions) => {
  const options = readOptions(rawOptions)
  const dispatch = ($: Parameters<typeof update>[0], ev: DagEvent) => update($, dag, s => apply(s, ev))

  const openPane = async ($: any, asked: boolean) => {
    const s = await read($, dag)
    if (!asked && (!options.autoOpen || s.isClosedByPerson || s.hasOpened)) return
    await dispatch($, { kind: 'set-flags', hasOpened: true, isClosedByPerson: asked ? false : s.isClosedByPerson })
    await $.ui.open({ id: PANE, title: TITLE })
  }

  on('session.start', async ($, e, next) => {
    const now = await $.clock.now()
    // A hot reload keeps the graph; a fresh session starts clean in the configured view.
    await update($, dag, s => (s.order.length > 1 ? s : freshState(now, options.defaultView)))
    await $.command.register({ name: 'dag', description: 'Toggle the Agents pane; `inspect` prints the tree, `reset` clears it', argumentHint: '[inspect|reset]' })

    let ticks = 0
    $.clock.every(TICK_MS, () => {
      void (async () => {
        const s = await read($, dag)
        if (s.order.length <= 1) return
        const at = await $.clock.now()
        ticks += 1
        if (isActive(s)) await dispatch($, { kind: 'tick', at })
        if (ticks % RECONCILE_EVERY === 0) {
          try {
            const agents = (await $.agent.list()) as ListedAgent[]
            await dispatch($, { kind: 'reconcile', agents, at })
          } catch { /* next tick */ }
        }
      })()
    })

    return next(e)
  })

  on('session.end', async ($, e, next) => {
    if (e.reason === 'clear') await dispatch($, { kind: 'reset', at: await $.clock.now() })
    return next(e)
  })

  on('agent.spawn', async ($, e, next) => {
    const started = await next(e)
    if (started.agentId) {
      await dispatch($, {
        kind: 'spawn', agentId: started.agentId, parentId: loopId(e.parentAgentId),
        label: e.description || e.name || e.subagentType, type: e.subagentType,
        isTeammate: e.isTeammate === true, name: e.name, teammateId: started.teammateId,
        workflowRunId: e.workflow?.runId, model: started.model, at: await $.clock.now(),
      })
      await openPane($, false)
    }
    return started
  }).catch(($, e, next) => next(e))

  on('turn.start', async ($, e, next) => {
    await dispatch($, { kind: 'turn-start', agentId: e.agentId, at: await $.clock.now() })
    return next(e)
  })

  on('tool.call', async ($, e, next) => {
    await dispatch($, { kind: 'tool-start', agentId: e.agentId, tool: String(e.tool) })
    try {
      return await next(e)
    } finally {
      await dispatch($, { kind: 'tool-end', agentId: e.agentId, tool: String(e.tool) })
    }
  }).catch(($, e, next) => next(e))

  on('turn.complete', async ($, e, next) => {
    await dispatch($, { kind: 'turn-end', agentId: e.agentId, reason: e.reason, usage: e.usage, at: await $.clock.now() })
    return next(e)
  })

  on('session.send', async ($, e, next) => {
    const sent = await next(e)
    if (sent.isDelivered) {
      await dispatch($, { kind: 'message', from: loopId(e.agentId), to: e.to, text: e.text, at: await $.clock.now() })
    }
    return sent
  }).catch(($, e, next) => next(e))

  on('ui.close', { id: PANE }, async ($, e, next) => {
    if (e.origin.kind === 'person') await dispatch($, { kind: 'set-flags', isClosedByPerson: true })
    return next(e)
  })

  on('ui.render', { component: 'Pane', requestId: PANE }, async ($, e) => {
    const { Box, Text, Button } = $.ui.resolve(e)
    const s = await read($, dag)
    const columns = Number.isFinite(e.props.bodyColumns) && e.props.bodyColumns > 0 ? Math.floor(e.props.bodyColumns) : 60
    const now = await $.clock.now()
    const o = { columns, glyphs: options.glyphs, now }

    const seg = (x: Segment, i: number) => (
      <Text key={`s${i}`} color={x.color} dimColor={x.dim} weight={x.bold ? 'semibold' : undefined}>{x.text}</Text>
    )
    const line = (r: Row, i: number) => <Text key={`r${i}`} wrap="truncate-end">{r.map(seg)}</Text>

    try {
      const hasAgents = s.order.length > 1
      const body = !hasAgents
        ? [<Text key="empty" dimColor>No agents yet. The pane fills when the session spawns one.</Text>]
        : s.view === 'cards' && columns >= CARDS_MIN_COLUMNS
          ? cards(s, o).map((c, i) => (
              <Box key={`c${i}`} marginLeft={2 * c.depth} borderStyle="round" borderColor={STATUS_COLOR[c.status].color}
                borderDimColor={STATUS_COLOR[c.status].dim} flexDirection="column" paddingX={1}>
                {c.rows.map(line)}
              </Box>
            ))
          : treeRows(s, o).map(line)
      const msgs = hasAgents ? messageRows(s, o) : []
      const canCards = columns >= CARDS_MIN_COLUMNS
      return (
        <Box flexDirection="column">
          <Box flexDirection="column">{body}</Box>
          {msgs.length > 0 && <Box flexDirection="column" marginTop={1}>{msgs.map(line)}</Box>}
          <Box marginTop={1} justifyContent="space-between">
            <Box gap={1}>
              {canCards && (
                <Button key="view" hotkey="v" plain label={s.view === 'cards' ? 'tree' : 'cards'}
                  onPress={() => update($, dag, st => apply(st, { kind: 'set-flags', view: st.view === 'cards' ? 'tree' : 'cards' }))} />
              )}
              <Button key="messages" hotkey="m" plain label="messages"
                onPress={() => update($, dag, st => apply(st, { kind: 'set-flags', showMessages: !st.showMessages }))} />
              <Button key="tools" hotkey="t" plain label="tools"
                onPress={() => update($, dag, st => apply(st, { kind: 'set-flags', showTools: !st.showTools }))} />
            </Box>
            <Text dimColor>{summary(s, options.glyphs)}</Text>
          </Box>
        </Box>
      )
    } catch (err) {
      return <Text dimColor>agent-dag: draw failed ({err instanceof Error ? err.message : String(err)})</Text>
    }
  })
}
```

```tsx
    const arg = (e.args ?? '').trim().toLowerCase()

    if (arg === 'inspect') {

    if (isOpen) {
      await $.ui.close({ id: PANE })
      return { text: 'Agents pane closed.' }
    }
```

````markdown
## Use

- The pane opens by itself the first time the session spawns an agent (in
  fullscreen mode from 110 columns; narrower terminals wait until you ask).
- `/dag` opens or closes the pane. `/dag inspect` prints the tree into the
  transcript. `/dag reset` clears it.
- With the pane focused (click it, or ctrl+x then tab): `v` switches between
  the tree and the cards view, `m` folds the messages section, `t` hides the
  tool chips on cards. Arrow keys scroll.
````
